# Research Sources

This document records research references for Football Agent art, audio, marketing, commercial planning, localization, testing, and legal/bureaucracy workflows. Research links are not asset licenses. Do not copy or ship content from these sources unless the actual asset/license terms are separately verified in `docs/ASSET_LICENSES.md`.

## Primary Map

- [FronkonGames/Awesome-Gamedev](https://github.com/FronkonGames/Awesome-Gamedev): broad gamedev resource index used as a research map, not a code or asset dependency. Selected sections below are relevant to Football Agent.

## Football Agent Research Rules

- Keep research separate from implementation dependencies.
- Prefer current official documentation for store policy, privacy, ads, analytics, and SDK rules.
- Do not make old or license-unclear links primary recommendations.
- For visual/audio inspiration, document the principle being adopted, not the source asset.
- Before release, use `football-agent-release-check` to confirm asset licenses, store claims, screenshots, trailer footage, and privacy disclosures.
